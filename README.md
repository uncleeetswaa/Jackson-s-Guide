# Jackson's Guide

A free workout and diet guide. It builds the week, the meals, and the pace from your numbers, then keeps today in front of you. Plans stay on this device.

**The Swing** is the prize: a kettlebell timing game. A better score can name the week or add a set. A worse run never takes a prize away.

## Run it

```bash
npm install
npm run dev
```

Open the local address the dev server prints.

This is general training education, not medical advice.
